# Anti-slop audit 001

Scope: hero mode gelap and real-time time card in the public microsite.

## Findings

1. **HIGH | R-25, R-34 | Portal sekolah can keep an unreadable text color in dark mode**

   `src/components/microsite/public-microsite.tsx:44-45,179` applies the portal label color through `--button-text-color` whenever the button style is not `card`. In `cardVars`, the dark-mode override at `:--button-text-color` only replaces the color when `button_color_mode !== "custom"`, so a custom button text color can remain too dark against the hero badge surface in dark mode. The label needs a dark-mode-safe foreground color while preserving the configured light-mode color.

2. **LOW | R-11 | Real-time time display is forced into a pill instead of following the card shape**

   `src/components/microsite/public-microsite.tsx:189` hard-codes `rounded-full` before the shared `${card}` class. This makes the time wrapper pill-shaped even when the configured card/button style uses a different radius. Remove the hard-coded pill radius so the time display follows the same card radius, border, background, and shadow language as the buttons.

## Direction read

The supplied screenshot and request provide the visual direction: a school information portal with a calm blue hero, readable dark-mode foregrounds, and rectangular card/button surfaces with deliberate radius variation. No separate `DESIGN.md` exists.
